## Synthetic storage and latency measurement

The integration measurement builds and activates a 200-student synthetic run in the test's temporary SQLite database. It measures the existing run-creation path and comparison GET with `performance.now()` and serializes the saved JSON payload/effective-input evidence to count bytes. The full-suite sample reported:

- Payload: 38,182 bytes
- Effective-input evidence: 20,753 bytes
- Combined diagnostic JSON: 58,935 bytes per run
- Create run: 19.12 ms
- Comparison GET: 7.56 ms

These are single-run synthetic test-process measurements, not a production benchmark. Repeated focused runs varied (for example 32.72 ms create / 14.31 ms GET), so latency should be treated as indicative only. No real student database or source spreadsheet was accessed.
