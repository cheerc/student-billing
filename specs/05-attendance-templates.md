# 点名表模板與 A4 輸出規格（P3）

## 1. 目標與已知限制

重用使用者已在 Windows Excel 校正的版型，直接產生可開啟列印的 `.xlsx`。第一階段不做此輸出。生成 XLSX 與生成跨平台相同 PDF 是不同承諾；後者沒有可用原生 Excel renderer 前，不列為必須功能。

六張來源表都有 A4（paperSize=9）設定；本次未讀到明確 printArea，也沒有手動 rowBreaks。不能因此斷言原版列印錯誤，也不能宣稱 clone 後必然一頁 A4。使用者的 Windows 校正結果是版型依據，P3 必須在同類環境實際重驗。

所有欄寬、列高、字型、合併、框線、邊界、縮放、頁首頁尾、隱藏欄、頁面方向、列印選项、相關 OOXML 關聯均須保留或有明確變更紀錄。不能把普通 HTML print 當作保留原 Excel 範本。

保真項目包含 sheetPr/pageSetUpPr.fitToPage、fitToWidth、fitToHeight及屬性未明設的狀態。六模板fitToPage=true、fitToHeight=0，fitToWidth未明設；課輔為fit-to-page模式、scale未明設，不能任意補scale或把未明設fitToWidth宣稱成已驗證的一頁寬。實際寬度和分页以原生Excel驗收。

## 3. TemplateDefinition 契約

一版模板包含：原始 XLSX hash、來源 sheetName、templateId/version、可選科別、固定欄位 bindings、學生槽位列表（含雙列名字）、重複表頭區塊、日期 cell 列表、日期政策、學生容量、溢出政策、printManifest、Windows 驗收記錄。

把班級 classId 明確指定給匯出，不再透過 `CELL("filename")` 推測。輸出工作表可使用班名，但不能依工作表命名改變資料對象。Excel 工作表 31 字元限制、禁止字元與重名要用穩定安全命名處理，完整班名留頁首。

P3 先由開發者維護六個已驗證 manifest，不先做讓使用者隨意上傳任何 Excel 就自動推導版型的功能。後續可新增模板版本，舊版本仍能重現歷史輸出。

legacy名單以FIND大小寫敏感搜尋班級全文是否含工作表名；受31字元及禁止方括號等命名限制影響，會把國小輔導四年級A/B合併。新工具不沿用此行為。輸出依同run的EnrollmentResolution精確classId名單；未解決映射不可偷偷用substring補名單。

## 4. 填值與公式策略

建議從來源模板複製版型，將外部依賴、名單、折扣、收費天數、老師與日期填成確定值；以經驗證的局部 OOXML patch 或可完整保真的 adapter 實作。避免重新建立整本樣式，也避免把原 15,341 個公式帶回輸出。

只留真正需要 Excel 編輯的空白點名格與既有手寫備註格。source hidden helper 欄可以保留為靜態值或空白，但不得留下 #REF!／#NAME? 或指向被移除工作表的引用。任何保留公式都需原生重算驗證。

基礎匯出內容：選定班的固定 run 名單、輸出日期、老師、排課時間、指定日期欄、學生姓名／英文名、學校班級／年級、需要的電話、基本或課程適用折扣、天數、親／園／額標记。不同模板照原需求填，不強迫每张有全部欄位。

bindings必須指向同一run的StudentCalculation／ClassStudentResult，天數和適用折扣不得在export重算；原模板TA/TT的獨立天數公式改填結果。格式順序：安親折扣為百分比＋「親」（如有）＋換行`\n(園)`（如有）；課輔／美語／數學僅百分比＋「親」。天數為數值＋`*額`（如有），數值欄與display分離。加強班%仍不擅填。年級未知或缺映射等needs_review在匯出前明示，不以ERP登記級距覆蓋計算值。

姓名解析保持 rawName；中文名與括號英文名為顯示衍生欄。學校原式 LEFT(就學資料,2)、班級取括號內等短縮規則可作 legacy display policy，但原始文字須可查。多個括號、姓名有空格、電話多行超長需有明確樣式驗收，不能直接截斷重要聯絡資訊。

## 5. 日期規則

不要由範本名稱猜週期。例如美語「每月2堂／3堂」表的種子公式往後加 7 日，使用 EDATE(...,2) 截止；實際是每週多個時段、跨兩月的公式形態。P3 UI 明確要求起迄日與每週時段，標題顯示真實日期範圍，模板名稱保持原名供辨識。

安親／課輔原 G4 起日期序列跳過星期日，並未跳過星期六。不得將它直接改成週一至五的日曆後宣稱完全相容。提供模板特定的 `legacyExcludeSunday` 政策並列入待確認；這與每週收費 5 天不是同一件事。

日期引擎以完整日期比較（含年份），不只比較 MONTH；支援跨年與閏年。起迄範圍 inclusive。假日停課／補課／取消日不自動推定；P3 可讓使用者在預覽確認生成日期並刪加單日，這些只影響點名表，不偷偷重算每週收費級距。

教師、時段的歷史來源固定 scheduleVersion；不拿「今天的老師」填過去已封存輸出。若所選日期跨多版本先要求選定政策或拆表，不猜。

## 6. 排序、分頁、溢出

預設依原始 ERP 列序，與現有 SMALL/ROW 找名單方式一致；可選姓名／年級排序但輸出紀錄保存實際 personCode 順序。名單不能因 UI pagination 只輸出當前 50 筆。

0 人：阻止產生看似有名單的檔，允許另行選擇「空白點名表」。容量內：未使用槽位清空，不留前一班學生。超過容量：複製已驗證的版面區塊／新分表，重複標題與日期、流水連續，不能縮字硬塞、截名單或插任意行破壞版面。

日期多於日期格容量時也需拆表，規則獨立於學生數。先按日期段再按學生頁組合，每段有相同學生順序；檔案標示分段起迄。每个模板確認容量與頁面切點後固定，不用 max_row 或可視空白猜可放多少人。

## 7. P3 驗收

每模板測 0、1、恰容量、容量+1、至少 2 倍容量；日期测最小、恰滿、超一欄；合併中文英文名、最長老師／班名、兩支電話、親／園／額混合標記。

資料面：學生 ID 集合、筆數、排序、每欄值、日期順序與 run 完全對應。结构面：保留版型元素、無壞關聯、無外部公式依賴、隱藏欄不意外列印。視覺面：Windows Excel 開檔無修復警告；使用 A4 Print to PDF／印表機，確認頁面不超界、不切名、不漏電話、不產生意外空白頁，原來分頁預期維持。記錄 Excel 版本、字型、印表機／PDF driver 設定。

没有 Windows 原生列印驗收時，結果標示「資料驗證通過，A4 原生列印待驗收」，不能只靠 Python 或網頁預覽聲稱完全符合。保留用户原範本，不在原檔上反覆試錯。
